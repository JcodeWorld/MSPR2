<h1>Projet MSPR2</h1>
<h2>Front-End REACT-Vite</h2>
<p>
Prerequis : Node JS et Npm
Instalation : npm install</p>
<h2>Back-End Symfony</h2>
<p>
Prerequis : Xamp ou Wamp et Composer
Installation : composer install
<br><br>
<strong>Creation fichier .env.local : </strong><br>
###> doctrine/doctrine-bundle ###<br>
DATABASE_URL="mysql://login:motdepasse@url?serverVersion=X.0"<br>
###> doctrine/doctrine-bundle ###<br>
###> nelmio/cors-bundle ###<br>
CORS_ALLOW_ORIGIN='^https?://(localhost|adresseIP:port)$'(chaque point est echappé avec\)<br>
###< nelmio/cors-bundle ###<br><br>
<strong>Creation base de données : </strong><br>
- Pour créer une base de donnée symfony console doctrine:database:create<br>
- Pour créer un fichier de création de table dans le repertoire migration, en se basant sur les entités. symfony console make:migration<br>
- Pour créer les tables en fonction du fichier crée précedement. symfony console doctrine:migrations:migrate<br><br>
<strong>Fixture : <strong><br>
Generation fake : symfony console doctrine:fixtures:load <br></p>
